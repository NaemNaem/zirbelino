# Known Limitations (Demo)

- Checkout is simulated (`status: demo`)
- Payment is not charged (`DemoPaymentService`)
- No real login / customer accounts
- No transactional emails
- Catalog intentionally limited to 20 products for demo
- Stock values are only as publicly visible / static snapshot
- Reviews are imported public snapshots, not live API sync
- Newsletter form will be UI-only until provider connected
- No order management backend
- B2B pricing / customer groups not reconstructed from public site
- X+1 gift logic / complex promotions not fully reimplemented yet
